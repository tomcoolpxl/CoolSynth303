A small update to CoolSynth 303, for Windows and Macs with Apple silicon.

## Install

On Windows: download `CoolSynth303-Setup-v0.2.1.exe` below and run it. It updates earlier versions in place.

On a Mac: open `CoolSynth303-Setup-v0.2.1.pkg`. It isn't signed, so macOS blocks it once: go to **System Settings > Privacy & Security** and click **Open Anyway**.

## What's new

- The panel starts in the Silver theme, after the TB-303's face. A theme you already picked in Options stays.

How to play it: see [the guide](https://github.com/tomcoolpxl/CoolSynth303#readme).
