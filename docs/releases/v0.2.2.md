An update to CoolSynth 303 against dropouts, for Windows and Macs with Apple silicon.

## Install

On Windows: download `CoolSynth303-Setup-v0.2.2.exe` below and run it. It updates earlier versions in place.

On a Mac: open `CoolSynth303-Setup-v0.2.2.pkg`. It isn't signed, so macOS blocks it once: go to **System Settings > Privacy & Security** and click **Open Anyway**.

## What's new

- The app renders its sound 50 ms ahead of the sound card, so a heavy moment (a note's attack, a knob turned fast, the Devil Fish pushed) no longer cracks or drops out. Keys, knobs and Play answer 50 ms later. The plugin in a DAW is unchanged.
- If the computer still falls behind at Best, the app goes to Light by itself and shows LIGHT where DSP was; the note playing then ends. After a calm stretch it goes back to Best.
- The oscillator's circuit is solved some 8 % faster, with the same sound.
- The latency on the Options' Audio page includes the 50 ms, and its CPU figure is the rendering's.

How to play it: see [the guide](https://github.com/tomcoolpxl/CoolSynth303#readme).
